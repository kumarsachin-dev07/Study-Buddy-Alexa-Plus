# Demo video script (aim for 90–150 seconds)

**Opening (15 sec):**  
“Students often have assignments and revision tasks scattered across different places. Study Buddy is a student productivity concept that brings a simple task list and conversational guidance into one interface.”

**Show the task list (25 sec):**  
“Here are today's tasks. I can add a task, mark it complete, or delete it. The progress indicator updates as I finish work.”

**Show the assistant (35 sec):**  
“I can ask Study Buddy to show my tasks or help me focus. For example, it suggests starting with one pending task for 20 minutes, then taking a short break.”

**Show the update (15 sec):**  
“I'll mark a task complete. The completed count and progress bar update immediately.”

**Be transparent (10 sec):**  
“This submission is a simulated Alexa+ experience prototype. The assistant is rule-based and does not connect to a real Alexa+ device or service.”

Before recording, make sure the app is working and replace this script with a truthful description of any changes your team actually makes.
