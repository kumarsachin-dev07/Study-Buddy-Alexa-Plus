# Study Buddy — Simulated Alexa+ Experience

A beginner-friendly student productivity prototype built for the Alexa+ track concept. It provides a simple web interface to add tasks, mark them complete, track progress, and interact with a rule-based assistant.

## Important disclosure

This is a **simulated Alexa+ experience**, not a real Alexa+ integration. The assistant replies using simple local rules; it does not connect to Amazon Alexa+, an external AI model, or an MCP server.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add a task, mark it complete, and try the suggested chat prompts.

No API keys, paid services, or installation are required.

## Features

- Add and delete tasks
- Mark tasks complete/incomplete
- Progress indicator
- Rule-based chat prompts:
  - `add revise chemistry`
  - `show my tasks`
  - `help me focus`
  - `make a study plan`
  - `mark one task complete`
- Saves task data in the browser's local storage

## Demo checklist

1. Open the app and explain the student productivity problem.
2. Add a new task in the task list.
3. Ask the assistant to show tasks.
4. Ask it to help you focus.
5. Mark a task complete and show the progress update.
6. State clearly that this is a simulated Alexa+ experience prototype.
